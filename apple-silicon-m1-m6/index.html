Apple Silicon, M1 to M6

Every Mac chip in one table. The three scores compare each chip with the plain M1 from 2020: 2.0× means twice as fast as an M1. Tap a column to sort.

Chip Multi-core Graphics Single-core CPU cores GPU cores Memory speed Max RAM
  • Single-core = how snappy everyday apps feel. Multi-core = heavy work like exporting, compiling, rendering. Graphics = games, 3D, video effects, local AI. Memory speed matters most for video and AI models.
  • Scores are for each chip's top version. Cheaper versions with fewer cores score lower (for example the 14-core M3 Max or the 15-core M5 Pro).
  • Ultra chips are only in the Mac Studio, not in laptops. There is no M4 Ultra, and Apple made no M6 Pro or M6 Max. Reports say the next Pro/Max chips are the M7 Pro/Max in 2027.
  • M5 Ultra: no independent scores yet. Apple says about 1.3× the M3 Ultra on CPU and 1.4× on graphics.

A new base chip often matches an older Pro

  • M4 ≈ M1 Pro on CPU, but less graphics power.
  • M5 ≈ M2 Pro / M3 Pro on CPU.
  • M6 beats the M3 Pro on CPU and graphics.
  • M4 Pro ≈ M3 Max on CPU, but the M3 Max has much more graphics power.
  • M5 Pro beats the M4 Max on CPU.

Which one fits

Web, office, study, video calls

Any chip in the table is enough. Get 16 GB of RAM or more: here RAM matters more than the chip.

Any base chip, or a cheap used M1 Pro

Coding, photo editing, light video

A Pro chip, or a newer base chip (M4, M5, M6), which matches an older Pro on CPU.

M1 Pro – M4 Pro, or M5 / M6

Heavy video, 3D, games, local AI

A Max chip. Graphics power, RAM and memory speed matter most here.
